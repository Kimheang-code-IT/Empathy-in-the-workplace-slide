## Usage

The whole deck is in `index.html` with styles and behaviour inlined. Open it
directly in a browser:

```bash
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

Deploy the repository as-is to any static host to publish it.
